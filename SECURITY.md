# Security

## Reporting a vulnerability

If you discover a potential security issue in this project, we ask that you
notify AWS/Amazon Security via our
[vulnerability reporting page](https://aws.amazon.com/security/vulnerability-reporting/).
Please do **not** create a public GitHub issue.

## Security model

See [Security model](README.md#security-model) in the README for how this
sample authenticates users, scopes MicroVM tokens, and routes requests, and
[Before you use this in production](README.md#before-you-use-this-in-production)
for the controls to add before production use.
