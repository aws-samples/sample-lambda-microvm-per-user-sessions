# Welcome to your own VS Code

This editor runs in a Lambda MicroVM that is yours for this session. Other users
can't reach it, and it does not share compute with them.

- Files you create here live on the MicroVM's disk. They survive when the
  MicroVM is suspended while you're away, and are deleted when it terminates.
- Open a terminal with **Terminal > New Terminal** - it runs inside the MicroVM.
- `git` and `python3` are installed.
